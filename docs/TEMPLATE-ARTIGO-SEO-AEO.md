## Checklist de Qualidade SEO/AEO

### ✅ Frontmatter
- [ ] Title com keyword e formato long-tail (<65 caracteres)
- [ ] Meta description responde diretamente à query (150-160 chars)
- [ ] Slug limpo com keyword principal
- [ ] Section correta definida
- [ ] `featured: true` para aparecer na magazine

### ✅ Conteúdo
- [ ] H1 único (=title)
- [ ] `<aside class="guide-keyfacts">` com 3-4 pontos-chave
- [ ] Imagem de destaque com alt text detalhado (50-125 chars)
- [ ] 8-12 links internos distribuídos no texto
- [ ] 3 CTAs intercalados (visual início + compacto meio + visual fim)
- [ ] 5+ FAQs com respostas detalhadas (3-8 linhas cada)
- [ ] Seção de fontes ao final
- [ ] Parágrafo final de resumo SEO

### ✅ Estrutura
- [ ] H2 para seções principais (3-5 seções)
- [ ] H3 para subseções quando necessário
- [ ] Parágrafos curtos (2-4 linhas)
- [ ] Listas bullet/numeradas para escaneabilidade
- [ ] Tabelas para comparações quando aplicável
- [ ] Bold para conceitos-chave

### ✅ AEO (Answer Engine Optimization)
- [ ] Resposta direta na primeira linha de cada FAQ
- [ ] Key facts respondem perguntas top-of-funnel
- [ ] Dados quantitativos (%, €, tempo, estudos)
- [ ] Comparações lado-a-lado em tabelas
- [ ] Processo passo-a-passo numerado
- [ ] Alt text descritivo e keyword-rich

### ✅ Conversão
- [ ] 3 CTAs com value proposition clara
- [ ] CTAs contextuais ao tópico
- [ ] Call-to-actions variadas ("Marcar", "Agendar", "Falar")
- [ ] Transparência LON quando aplicável
- [ ] Links para artigos relacionados (cluster)

### ✅ Técnico
- [ ] Imagens com width/height definidos
- [ ] `loading="lazy"` em imagens não-hero
- [ ] `decoding="async"` em todas imagens
- [ ] Links internos com anchor text descritivo
- [ ] URLs relativas (/blog/slug)

## Boas Práticas de Escrita

### 1. Responda Diretamente
❌ **Errado**: "Para saber se Mounjaro é indicado, é importante considerar vários factores..."  
✅ **Correto**: "**Mounjaro é indicado para IMC ≥30 ou IMC ≥27 com comorbilidades** — avaliação médica determina elegibilidade baseada em..."

### 2. Use Dados Quantitativos
❌ **Errado**: "Mounjaro é eficaz para perda de peso"  
✅ **Correto**: "**Mounjaro perda peso média 15-20%** peso corporal 72 semanas (ensaios SURMOUNT)"

### 3. Seja Específico sobre Portugal
❌ **Errado**: "Mounjaro está disponível"  
✅ **Correto**: "**Mounjaro disponível Portugal farmácias desde setembro 2022** — não comparticipado SNS perda peso, custo €150-350/mês"

### 4. Formate para Escaneabilidade
❌ **Errado**: Parágrafos longos sem estrutura  
✅ **Correto**: Listas bullet, bold em conceitos-chave, parágrafos 2-4 linhas

### 5. Links Contextuais
❌ **Errado**: "Leia mais [aqui](/blog/slug)"  
✅ **Correto**: "Saiba mais sobre [efeitos secundários GLP-1](/blog/efeitos-secundarios-glp1)"
